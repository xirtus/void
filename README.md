# Void Linux Config Backup

This repository contains backup configuration files and scripts for a Void Linux installation featuring:
- Hyprland (Wayland Compositor)
- River (Dynamic Tiling Wayland Compositor)
- Waybar (Status Bar)
- Runit (Service Management)
- Kitty (Terminal Emulator)
- Btop (System Monitor)
- Yazi (File Manager)
- Mpv (Media Player)

## Contents
- `dotfiles/`: Configuration files located in `~/.config/` and shell profile files.
- `runit/`: Runit service definitions (e.g., Pipewire, Wireplumber).
- `scripts/`: Custom startup scripts (`start-*.sh`).
